# BiTadilat payment flow presentations / Ödeme akışı sunumları

Three self-contained HTML pages, each in Turkish and English. / Her sayfanın Türkçe ve İngilizce sürümü var.

| Page / Sayfa | Türkçe | English |
|---|---|---|
| Written explanation: flow table, fraud safeguards, 6 alternative models, comparison / Yazılı anlatım | [1-odeme-akisi.html](1-odeme-akisi.html) | [en/1-payment-flow.html](en/1-payment-flow.html) |
| Interactive money map with scenario player, timeline, outcome bars / Etkileşimli para haritası | [2-para-haritasi.html](2-para-haritasi.html) | [en/2-money-map.html](en/2-money-map.html) |
| Auto-playing 11-scene animation / Otomatik oynayan 11 sahnelik animasyon | [3-odeme-animasyonu.html](3-odeme-animasyonu.html) | [en/3-payment-animation.html](en/3-payment-animation.html) |

## How to open / Nasıl açılır

Double-click a file, or from the repository root: / Dosyaya çift tıklayın ya da depo kökünden:

```
open docs/sunum/1-odeme-akisi.html
open docs/sunum/en/1-payment-flow.html
```

Fonts (Manrope, IBM Plex Mono) load from Google Fonts; offline the pages fall back to system fonts and still work. / Yazı tipleri Google Fonts'tan yüklenir; çevrimdışıyken sistem yazı tipine dönülür, sayfalar yine çalışır.
